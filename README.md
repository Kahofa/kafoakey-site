# KafoaKey — сайт-визитка

Статичный сайт магазина премиальных ковриков Artisan: `index.html` (главная) и `accessories.html` (аксессуары).

## Что где
- `js/config.js` — все ссылки, заглушки `{{...}}`, отзывы, цвета, размеры и каталог ковриков. Меняйте данные здесь.
- `js/main.js` — карточки, смена цвета, FAQ, курсор, анимации (GSAP, ScrollTrigger, Lenis с CDN).
- `css/style.css` — общий стиль обеих страниц.
- `img/` — логотип, фавикон, фото ковриков по цветам (`<модель>-<цвет>.jpg`), коврик первого экрана.

## Запуск
Открыть `index.html` в браузере или запустить локальный сервер в папке проекта:

```
python -m http.server 8765
```

Фото ковриков взяты с artisan-jp.com как временные — перед публичным запуском замените своими или получите разрешение Artisan.
